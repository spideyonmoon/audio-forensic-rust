## Investigated attempts and finite limitations

Initial Clippy command needed a literal quoted `--` through PowerShell's wrapper;
then Clippy found the collector helper's argument count. Refactored its location
arguments; final all-target check passed. Patch context/operation mismatches
applied nothing and were repaired with smaller exact edits. The broader debug
regression was slow and stopped during source tests; optimized MSRV checks
completed the same set. An optional process inventory was denied and not used;
the task's identified debug executable was stopped directly. These are not
detector/oracle failures or a claimed full debug regression.

Initial differential expectation discovered MediaInfo 24.01 projection losses:
the pinned extractor misses normalized track/album ReplayGain fields and maps
RIFF IART to `other[Director]`, leaving artist empty. The failing receipt and
empty Python outputs remain preserved in `differential-initial/`. Rust retains
the raw gains/artist; subsequent checks compare equivalent pinned fields exactly
and separately verify the original values against MediaInfo/raw generated text.
These are D12 projection differences; no audio or frozen reference was changed.

Finite coverage/unavailability is explicit in the validation document: FLAC
vendor/comments/picture descriptors; WAV INFO/raw XML/BEXT text. WAV ID3,
non-INFO LIST and other binary/unknown ancillary structures remain opaque
descriptors; this is not a universal tag-format parser. Header fields unavailable
in these containers remain null/listed. Other formats, complete P07 CLI/product
workflows and MQA confirmation retain their own packets.

Integrated ReplayGain requires the same caller-held source snapshot; matching
names/headers cannot prove identity because metadata does not read/hash PCM.
Its native LUFS prefix/method/hash remain explicit, and nonfinite/failed/unequal
or unusable inputs never fabricate a comparison. Editable tags never contribute
to an ancestry score; measurement ancestry/index remain INCONCLUSIVE/null.
