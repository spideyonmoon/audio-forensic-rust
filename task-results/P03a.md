# P03a — bounded tool statistics and distinct DR

Date: **2026-10-05**. Status: **DONE**. Engine **0.25.0**.

P03a is the only remaining P03-family card; no P03b/P03c cards exist.
G03 tool aggregates and G04/G06 are implemented for currently supported PCM
streams. Next is **P04c**, reference basis/segment/scatter/transform adapters.
P07 owns CLI/product exposure; new formats, endgame and Android work are outside
this packet. Existing dirty/untracked work is retained.

`analyze_path_with_tool_statistics` / `analyze_source_with_tool_statistics`
return unchanged native measurements, P03 byproducts and a separate version-1
statistics product, sharing the worker, guarded source, selected stream/prefix,
two PCM passes/hash, callback and cooperative cancellation/deadline. No runtime
subprocess, new dependency or duration-sized PCM. Measurement schema 0.18.0,
policy, ancestry INCONCLUSIVE and null evidence index remain intact. Existing
APIs do not allocate this opt-in collector.

Native-lane/overall astats implement signed-maximum integer normalization,
50 ms EWMA extrema and circular noise queue, entropy, range, extrema/run/absolute
peak counts and nonzero-sign crossings. Exact counters and channel/overall
aggregation are separate. Correct linear/dB crest and unavailable sentinels have
explicit units/reasons. All 15 canonical SoX stat keys use actual signed32
interleaved conversion and deltas, with conversion clips and exact sample count.
DR independently implements pinned f32 three-second RMS/peak histograms, second
peak/top-20% whole-bin selection and tail/no-data quirks. Per-lane and overall
numbers and labels remain distinct; no crest/LRA substitute or quality grade.
The unequal-stereo control has Python legacy DR6 versus overall DR0.

Legacy audit executes the pinned Python text choices: last occurrences,
omitted trough, six-to-two-decimal rounding, raw linear crest mislabel and first
nonnegative DR match. Its unanchored Peak count regex selects Abs Peak count;
these are separately named product measurements. Undefined one-sample SoX
Windows nonfinite text is retained only in audit. Encoding guesses/header/path
warnings remain local tool diagnostics rather than canonical numeric keys.
Full definitions/domains/resource accounting: TOOL_STATISTICS_VALIDATION.md.

At 384 kHz stereo, two astats f64 window arrays and 8192 u64 entropy bins per
lane plus two 32769 u64 DR histograms per lane have **1,794,080 payload bytes**.
This excludes bounded scalar/report/container overhead and existing native/P03
buffers. No array grows with duration or block count. Histogram reductions check
controls in bounded batches; fixed-array capacity and failure propagation are
tested. Source packet/blocking-I/O cancellation limitations remain cooperative.
Failed/unsupported/cancelled/timed-out products suppress measurements and scope.
