## Implemented packet

SharedJobs persists job/attempt UUIDs, ordered item IDs, feature/options and
states before acquisition. One serial worker and two queued operations; queued
work owns grant references but no open sources/copies. Bounded control queue,
fresh retry attempts/tokens, attempt-bound latest progress and cancellation.
Returning from decoding without finalizing is a host failure. Worker adapters
close leases before terminal manifest publication. Cancel preserves committed
per-item bytes/outcomes; unfinished process-recreated jobs become interrupted.

Nonexported same-process START_NOT_STICKY foreground service promotes before
worker launch. API 30–33 ordinary type; API 34 specialUse; API 35–36
mediaProcessing. Notification cancellation, denied-notification UI, explicit
API-33+ permission request, per-operation 30-minute watchdog and bounded partial
wake lock. Platform timeout stops foreground/service without a main-thread join.
The app observes immutable snapshots at 250 ms while started. Workspace selection
is retained across rotation by its ViewModel; Activity teardown does not own jobs.

ResultStore retains original bounded bytes and explicit kind/version/hash/size
descriptors, outcomes and atomic manifest v1. Reservations feed input disk safety;
32 entries/512 MiB history evicts oldest unleased entries, never live jobs/readers.
Relative single-file paths only, create-new payloads, fsync/atomic rename, hash
validation before loading/export. Unknown payload versions remain original bytes
and dispatch unsupported_version. Process startup reconciles committed manifests,
removes orphan payloads/snapshots/probe outputs and releases only journaled
app-owned input grants. Grant references span queued/running work and selection
replacement; preexisting owner grants remain outside ownership.

NativeJob polls exact transport at 250 ms and waits for actual native release on
close/cancel. A failed release proof protects pins and blocks admission until
force-stop/recreation instead of deleting a potentially live source.

ResultDestination uses explicit SAF ACTION_CREATE_DOCUMENT. ResultTransfer permits
one transfer and records the last 32 attempt receipts. Failure leaves local
results intact. Sharing exposes only bounded copies under FileProvider's cache
root with temporary read grants; history deletion cannot invalidate these copies.
Copies expire for cleanup after ten minutes on the next share request, with a
32-copy/128-MiB bound. No automatic upload or silent overwriting workflow.
