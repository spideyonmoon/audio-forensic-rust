## Implemented

Engine 0.28.0 enables only Symphonia 0.5.5 ALAC/MP4 feature crates. New
`src/mp4.rs` bounds movie metadata, tables, packet geometry and cookie-derived
native parameters before decoding. It supports sample-entry versions 0/1,
both movie layouts, 32/64-bit box sizes/offsets, identity edits, bounded sync
and zero composition offsets. Unknown source length is discovered with a
seek-to-end and exposed only to the decoder. Actual PCM retains native
channels/16/24-bit precision and canonical signed32 hashes in all passes.
ALAC decoder panics are isolated as structured failures under default unwind;
A01 must preserve that boundary if choosing another panic strategy.

P02 version-1 metadata covers movie/track/media ilst text/freeform namespaces,
duplicates, unknown UTF-8 tags, decimal numeric tags, original wire lengths,
bounded artwork and explicit opaque binary/UTF16 descriptors. CLI directory
input includes .m4a. Existing measurement schema 0.18.0, policy, ancestry and
null evidence index remain unchanged. See ALAC_VALIDATION.md for explicit limits.
