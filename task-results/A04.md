# A04 — shared workspace input and staging

2026-10-08. **Implementation complete; Android CI acceptance pending.**

Shared owns single/multiple/tree SAF contracts (including returned grant flags),
selection/item UUIDs and generation, bounded nonrecursive enumeration, grant
ownership, one serial acquisition/probe lane, exact encoded hashes and counted
snapshot/output leases. Direct selection collapses document identities, preserves
equal names, and rejects more than 32. Folder listing stops at 512 records or 32
candidates with an explicit incomplete notice and requires a smaller confirmed
set before probing. Names are bounded to 1024 UTF-8 bytes.

All providers, including seekable files and unknown-length pipes, copy through a
256 KiB buffer to a create-new partial. Actual bytes are capped at 700 MiB;
known-size admission and per-write free-space checks retain the 256 MiB margin
and 64 MiB probe-output allowance. Copy completion fsyncs and atomically renames
before publishing a read-only snapshot. Failure/cancellation deletes partials.
A sole snapshot also bounds staging below 768 MiB. Counted leases retain snapshots
and output directories until native terminal release or active_handle exit after
close. Failed transport cannot authorize deleting a possibly live native source.
A05 owns shared storage reservations/history/orphan recovery and persisted jobs.

Native metadata probes supply actual content capability, including ALAC versus
AAC in M4A. The workspace shows per-item failures and gates independent routes;
Forensics allows explicit mixed outcomes, Spectrogram needs one supported input,
and Compare needs supported inputs and an explicit same-track declaration.
Reference scope budget previews are derived from probed rates/declared frames;
A06b owns the actual common-scope choice and live comparison execution. Features
receive selection/probe identities and the shared owned-acquisition function;
reacquisition rejects encoded-hash changes. No feature import system or core/DSP
change. Feature execution/results and background lifecycle remain A05/A06/a/b.
