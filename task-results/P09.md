fresh PCM/DSP/700 MiB/RSS campaign, private recordings, calibration/MQA research,
DSD conversion, Android target/link/APK/device, remote CI, commit/push/publication
or external backup. P08 optimized MSRV tests used LTO=false/codegen-units=16;
acceptance does not relabel that binary as a default-profile distribution build.

separate; F02's frozen future DSD contract remains intact. Existing dirty/untracked
work and private/pinned reference inputs are preserved. All P08/P09 receipts are
local ignored evidence, not Git history, publication or an external backup.
