# Embedded canvas font

Unmodified Noto Sans Regular from the archived upstream repository:
https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf

Retrieved 2026-10-06. The SIL Open Font License 1.1 and copyright notice are
included in `OFL.txt`; distribute that notice with the application. No system
font installation or network access is required at runtime. Rasterization uses
the fixed embedded font, never arbitrary caller-supplied font bytes.

SHA-256 (NotoSans-Regular.ttf):
`b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5`

SHA-256 (OFL.txt):
`0dab92d0544f7b233403f14b84a663bdbfa746982eda629e7f4f9ffe1b036feb`

Title text uses per-character Unicode glyphs and kerning. Complex-script shaping,
emoji/color fonts and universal Unicode coverage are outside this renderer.
PNG metadata retains the bounded title; unsupported characters use the font's
visible missing-glyph mark. Do not describe missing glyphs as transliteration.
